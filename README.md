# Deepwalker

Новая мобильная Action RPG с нуля: мрачное подводное фэнтези, Глубинщик, исследование руин и стабильная работа в браузере Android.

Первый прототип использует Phaser 3 без сборщика, фиксированный джойстик, одну тестовую локацию, двух врагов, камеру, препятствия, столкновения и базовый урон.

Запуск: открыть через GitHub Pages или статический HTTP-сервер.
